## Classification rules

- **Missing Implementation → Implement → Verify:** a concrete source/behavior defect with an actionable fix under approved requirements.
- **Plan Gap → Plan → Verify:** required evidence, target, access, control or scheduled execution has not been supplied/performed. This includes an execution-readiness gap in an existing plan, not necessarily a missing task definition.
- **Ambiguous Requirement → Clarify → Verify:** an owner-specific value/input/authorization is unresolved. It does not mean the already-approved shared-cart journey is ambiguous.

“Continue” is **YES/NO for the finding's next work/acceptance**. A NO blocks that dependent task and release signoff; it does not prohibit committing/publishing the implemented feature branch. No merge or main-branch push is authorized.
