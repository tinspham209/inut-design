# Historical plans

The dated documents in this directory are retained as implementation history,
not as current product or deployment instructions.

Use them to understand why a decision was made. Before applying any plan:

1. compare it with current source code and tests;
2. use current package versions and Cloudflare production runbooks;
3. verify that the proposed route, API, analytics or platform behavior still
   exists;
4. do not treat an old completion claim as current evidence.

Current release operations live in `docs/operations/`. Current engineering
workflow lives in `.agents/skills/inut-design-workflow/`.
