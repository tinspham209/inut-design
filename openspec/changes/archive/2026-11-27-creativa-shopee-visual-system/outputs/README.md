# Creativa Shopee output handoff

## Batch folders

```text
outputs/
  generated/
    batch-01/
      chatgpt/
      gemini/
  edited/
    batch-01/
  approved/
    batch-01/
```

## Rules

- `generated/`: untouched AI outputs. Keep the prompt, tool, batch, source design, and version in the filename or a same-name note.
- `edited/`: Canva/Figma outputs with editable source retained by the team. Final Vietnamese text, logo, badges, model labels, prices, and coverage labels belong here.
- `approved/`: reviewed exports only. An asset enters this folder after artwork fidelity, rights, fact, brand, and thumbnail checks pass.
