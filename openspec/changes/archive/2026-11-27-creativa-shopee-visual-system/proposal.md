# Proposal

## Why

INUT Creativa has a live 22-design MacBook-skin catalog, but it does not yet have a repeatable visual production system for a Shopee storefront. The existing shop references, Creativa website, and approved Instagram grid point to related but different visual habits; without a shared contract, generated images can become inconsistent, distort product artwork, produce inaccurate text, or optimize for mood at the expense of thumbnail recognition.

This change establishes one evidence-based Shopee asset system before production begins, so the team can reuse the approved marketing language while preserving the actual products and reducing support questions about models, coverage options, and application.

## What Changes

- Define a Shopee-specific visual hierarchy for INUT Creativa that uses the approved marketing grid as the primary brand reference and the competitor shop only as a commerce-pattern reference.
- Define a production inventory for shop identity, collection covers, listing slides, model/coverage explainers, application guidance, and campaign assets.
- Separate generation-ready source inputs from final editable text, logos, product names, model labels, and factual claims.
- Define repeatable asset templates and a batch order, beginning with grouped collections before optional per-design listings.
- Require source-fidelity and thumbnail checks for every generated or composited product image.
- Record rights-review requirements for artwork with third-party or character/vehicle branding.
- Move the existing research note and all supplied reference images into the change as source material.

## Capabilities

### New Capabilities

- `creativa-shopee-visual-system`: Defines the durable requirements for planning, generating, reviewing, and organizing Creativa storefront image assets without changing product or commerce behavior.

### Modified Capabilities

None.

## Impact

- Adds planning artifacts under `openspec/changes/creativa-shopee-visual-system/`.
- Relocates the existing `tasks/creativa/idea.md` and reference images into the change.
- Guides future Canva/Figma, ChatGPT image generation, and Shopee upload work.
- Does not modify the Next.js application, Sanity catalog, checkout flow, pricing, order data, or analytics.
- Does not authorize publication or establish production claims that are not already supported by authoritative product data.
