# Product requirements and QA

Inputs: route path and source `content.md`. Read the file and existing category
data/template before generation. Resolve missing/unclear fields specifically:

- Category/hierarchy: Event, Marketing, Office, Photo, Souvenir, Sticker or an
  actual existing category file; do not invent a category name/file.
- Hero/type/gallery images: real paths or reported `/branding/logo.avif` placeholder.
- CTA label: “Đặt in ngay” or supplied label; primary conversion goal and contact
  form `type` identifier must match actual integration.
- Comparison table: column criteria and source-supported comparison data.
- SEO title/description/keyword/canonical route.
- Main highlights and appropriate icons (often four, not invented facts).

Do not generate route/data until category and main highlights are confirmed by
the approved brief, supplied content or targeted user confirmation. Avoid asking
again for confirmed requirements. Validate assets, hero/showcase, SEO uniqueness,
responsive type grids (2 mobile / 4 desktop where the template supports it), CTA
tracking through both gateways, contact type and content completeness.
