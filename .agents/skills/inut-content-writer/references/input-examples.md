# Canonical input examples

These recipes replace former standalone prompt wrappers. Read the relevant
skill explicitly if the client doesn't discover it; don't recreate mirrors.

## Compact blog batch

`Sticker Magnet | 2 | /services/sticker/sticker-magnet`

Optional additions: `keyword: sticker nam châm Đà Nẵng; audience: chủ shop;
date: 2026-10-08; angles: phân biệt vật liệu, chuẩn bị artwork`.
Multiple lines are separate groups and counts are per product, not a global total.

`Pin cài áo mica | 2 | /services/an-pham-luu-niem/pin-cai-ao-mica`

If a supplied Pin URL disagrees with canonical source, inspect route/redirect
evidence. Report a unique correction; don't guess if multiple products fit.

## Product marketing copy (not a blog batch)

`Viết nội dung sản phẩm INUT: [tên]; keyword: [từ khóa]; audience: [nhóm].`
Use the product-copy structure; missing technical, price, MOQ or timing facts
remain omitted pending confirmation, not filled with defaults.

## Safe review/update

`Kiểm tra CTA và metadata chỉ trong [file được chỉ định]; giữ nguyên nội dung
người dùng, chỉ sửa lỗi đã được yêu cầu.` Remove a duplicated visible URL bullet
only in authorized files. Source uncertainty belongs in the report, not prose.

## Landing page handoffs

`Draft only: [product], [keyword], [audience]` → automation brief, no code writes.
`Create a new product page: [brief]` → automation, then generator after content.
`Generate route [route] from [existing content.md]` → generator, not a new brief.
